# Contributing and feedback

This repository contains public product documentation and images. The main web/iOS application source is private, but the **macOS Campus Rhythm Mini** sticker is open source at [campus-rhythm-mini](https://github.com/jinghengxu74/campus-rhythm-mini) — code contributions and stars are welcome there.

If the Mac sticker or this showcase helps you, please **star** [campus-rhythm-app](https://github.com/jinghengxu74/campus-rhythm-app) and [campus-rhythm-mini](https://github.com/jinghengxu74/campus-rhythm-mini) on GitHub.

## Helpful contributions

- Documentation corrections, unclear instructions and broken links.
- Reproducible interface/import/planning problems with sanitized steps.
- Accessibility observations identifying the device/browser and affected task.
- Usability feedback through the optional [survey](https://forms.gle/8ue3LXgotZLrxNzX9).

Open an [issue](https://github.com/jinghengxu74/campus-rhythm-app/issues) with:

1. The task you were trying to complete.
2. The screen and minimal steps to reproduce.
3. Expected behavior and actual behavior.
4. Browser/OS or native development-build version.
5. A sanitized screenshot if useful.

Do not include feed URLs, tokens, emails, account exports or private calendar/health records. Do not submit third-party artwork without permission.

Small documentation pull requests are welcome for review; acceptance is not guaranteed. Feature requests may inform the roadmap, but no support SLA or delivery date is promised.

For vulnerabilities, follow the private-reporting guidance in [privacy boundaries](docs/PRIVACY.md) rather than posting exploit details publicly.
